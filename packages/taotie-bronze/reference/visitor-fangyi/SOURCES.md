Notes

- Both Commons images were downloaded as Commons' own 1280-px renditions. They were re-encoded (JPEG q90, metadata stripped) and kept at their native size, which is at or below 1800 px.
- The CC BY-SA 4.0 file must keep its attribution and share-alike terms if it is redistributed. The project only uses it as a modelling reference and does not ship it in the app.
- The two Commons photos are matched to the owner's photograph in `dossier.md` §a. Treat the match as a strong identification, not a museum-confirmed one: the Art Institute's own collection API was not on the allowed host list, so the accession number is unverified.
- Comparanda that were inspected and rejected (they are not this object): Met 43.24.5a–b (Western Zhou, mid-10th c. BC); Freer F1930.54a–b (the Ling fangyi 令方彝); a Luoyang Museum fangyi (Gary Todd photo on Commons); Harvard Art Museums 11th–10th c. BC fangyi (Daderot photo).
