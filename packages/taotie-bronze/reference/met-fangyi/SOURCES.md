# Sources — met-fangyi (Met 1974.268.2a, b)

All files derive from The Metropolitan Museum of Art's Open Access photographs of this object.
The Met publishes them as public domain (CC0 1.0; API `isPublicDomain: true`). No attribution is
legally required, but the credit line is given as the Met asks.

Credit line: The Metropolitan Museum of Art, New York. Purchase, Arthur M. Sackler Gift, 1974
(acc. 1974.268.2a, b). Public domain (CC0 1.0).

Object record: https://www.metmuseum.org/art/collection/search/44776
API record: https://collectionapi.metmuseum.org/public/collection/v1/objects/44776

These three are the only photographs the Met publishes for the object (primaryImage + 2
additionalImages). Wikimedia Commons holds only copies of the same three files
(`商 青銅方彜-Ritual Wine Container (Fangyi) MET DP15139[678].jpg`). **There is no true front
view and no top view.** The `detail-*` files are crops of the full-resolution originals:
DP151396 is 2882×3842 and DP151398 is 3000×4000. Each was downscaled to ≤1800 px on the long
side (ImageMagick `-resize '1800x1800>' -quality 86`).
