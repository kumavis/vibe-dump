# Sources: met-fangding (Met 49.135.2)

All files come from the Open Access photographs of this object at The Metropolitan Museum of Art. The Met
publishes them as public domain (CC0 1.0; the API returns `isPublicDomain: true`). The licence requires no
attribution, but every file carries the credit line the Met asks for.

**Credit line:** The Metropolitan Museum of Art, New York. Bequest of Addie W. Kahn, 1949
(acc. 49.135.2). Public domain (CC0 1.0).

- Object record: https://www.metmuseum.org/art/collection/search/60594
- API record: https://collectionapi.metmuseum.org/public/collection/v1/objects/60594
- Wikidata: https://www.wikidata.org/wiki/Q116313080

The Met publishes six images: the primaryImage (three-quarter view) and five additionalImages (a
**near-orthographic long face**, a **near-orthographic short face**, the interior inscription, and two
ink rubbings of that inscription). Wikimedia Commons holds only copies of the same files
(`商 青銅方鼎-Rectangular Cauldron (Fangding) MET DP14073[5-8].jpg`, `DP15332[34]`). There is no top view.

Originals: DP140735 and DP140736 are 4000×3000. DP140737 and DP140738 are 2000×1500. DP153323 is 3433×2466.
The full views were downscaled to ≤1800 px on the long side (ImageMagick `-resize '1800x1800>' -quality 86`).
The `detail-*` files are crops of the originals at full resolution (each is already ≤1800 px, so none was
rescaled). Originals are kept in the scout work dir (`.work/r5-scout/orig/`), not in the repo.
