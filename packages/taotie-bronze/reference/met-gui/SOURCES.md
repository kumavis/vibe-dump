# Sources: met-gui (Met 62.217)

All files come from the Open Access photographs of this object at The Metropolitan Museum of Art. The Met
publishes them as public domain (CC0 1.0; the API returns `isPublicDomain: true`). The licence requires no
attribution, but every file carries the credit line the Met asks for.

**Credit line:** The Metropolitan Museum of Art, New York. Gift of Count and Countess Bernard d'Escayrac,
1962 (acc. 62.217). Public domain (CC0 1.0).

- Object record: https://www.metmuseum.org/art/collection/search/44617
- API record: https://collectionapi.metmuseum.org/public/collection/v1/objects/44617
- Wikidata: https://www.wikidata.org/wiki/Q116314274

The Met publishes seven photographs: the primaryImage and six additionalImages. They are **both main faces
near head-on** (front and back, each centred on the mask's nose ridge), **both handle ends**, a **top** view
into the bowl, a **bottom** view and a close-up of a cast mark inside the bowl. Wikimedia Commons holds
copies of the same files (`商 青銅簋-Food Serving Vessel (Gui) MET DP21826[1-4].jpg`, `DP21860[2-4]`).

Originals: all are 4000×3001 (DP218602 is 3001×4000). The full views were downscaled to ≤1800 px on the long
side (ImageMagick `-resize '1800x1800>' -quality 86`). The `detail-*` files are crops of the originals at
full resolution (each is already ≤1800 px, so none was rescaled). Originals are kept in the scout work dir
(`.work/r5-scout/orig/`), not in the repo.
