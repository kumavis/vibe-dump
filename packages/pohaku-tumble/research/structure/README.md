# Structural study — working notes

The report is [`../STRUCTURE.md`](../STRUCTURE.md). It ends with a verification section, which lists the fact-checker's and critic's corrections. This folder holds what each analyst wrote and ran:

| folder | level |
| --- | --- |
| `phonology/` | inventory, oppositions, minimal pairs and their (lack of) meaning |
| `derivation-reduplication/` | hoʻo-, -na, other affixes, reduplication |
| `grammatical-paradigms/` | pronouns, possessive a/o, deixis, directionals, articles |
| `lexical-fields/` | kinship, orientation, counting, colour, body-part extension |
| `phrase-syntagm/` | head + modifier: compounds and phrases, collocations in Hawaiian Wikipedia |
| `historical-structure/` | sound correspondences, structure history left in words, inherited compounds |
| `synthesis/`, `factcheck/`, `critic-completeness/` | the synthesis and the two verifiers |

The `scripts/` folders hold the scripts as they were run, against a scratch layout. Paths into it read `(scratch)/` or `structure/…`, and the inputs are the caches built by `../roots/fetch_sources.sh` and `../pollex/`. Expect to edit paths before re-running.

Downloaded papers, corpus pickles and large intermediate tables were left out. They are either copyrighted or regenerable.

This was research only: nothing here changes DESIGN.md.
