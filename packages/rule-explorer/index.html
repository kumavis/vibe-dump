reading the graph
  • Bright ring — an attractor cycle. A period-7 orbit is drawn as a literal 7-gon; a fixed point is a lone dot.
  • Height — steps left before you fall into the attractor. Every edge points strictly downhill, so time runs like gravity.
  • Each cone — one basin of attraction. Separate cones mean states that can never reach each other.
  • Sparks — states moving forward one tick at a time: down the trees, then circling the ring forever.
  • Outer tips — garden-of-Eden states, which nothing maps to. Only a reachable past has none.

Each node is one global state of a length-N ring (wrap-around). A deterministic rule sends every state to exactly one successor, so the whole thing is a functional graph — transient trees draining into cycles.

Ring too large to graph

A 28-cell ring has 268,435,456 states, and the graph needs a node for every one — roughly 22 GB. It draws up to 16 cells.

The spacetime view runs at any size, and this is where rule 110's gliders live: ring sizes that are multiples of 14 carry its ether.
