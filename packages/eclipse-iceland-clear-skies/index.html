How this works

Totality times are computed per location from NASA's published Besselian elements (ΔT = 71.4 s) — accurate to a few seconds. Cloud cover comes from four independent weather models (ICON, GFS, ECMWF, and Open-Meteo's best match), sampled at each grid point's own mid-eclipse instant and blended into a sun-visibility score that weights low cloud most and thin cirrus least. Because the Sun is so low, each cloud layer is sampled along the actual line of sight — low cloud (~1.2 km) a few km toward the Sun, mid cloud (~4.5 km) ≈10 km out, cirrus (~8.5 km) ≈18 km out — so clear sky overhead with a cloud bank to the WSW scores poorly, as it should. Doppler radar shows precipitation falling now — use it to sanity-check the forecast against reality as the hour approaches. Everything refetches automatically as new model runs land.

Mind the low Sun: during totality it stands only ≈25° high toward the WSW, so a fjord wall or mountain can hide it even under clear sky. Every listed spot (and any spot you click) is checked against a 90 m terrain profile along the Sun's exact azimuth — ⛰ flags a crowded horizon. Favor west-facing shores and open ground.
