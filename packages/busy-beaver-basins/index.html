Reading it
  • Amber cone — the halting basin. Every configuration in it eventually stops. The bright core is the halt state itself.
  • Cyan cones — basins that never halt. The glowing ring at the bottom of each is the cycle it is trapped in; a period-9 orbit is drawn as a literal 9-gon.
  • Magenta node — the blank tape, where a busy beaver starts. The thread hanging off it is its whole run; its height is the machine's score.
  • Height — steps left before the machine's fate is sealed. Every edge points strictly downhill, so time runs like gravity.

The catch

A tape of N cells has finitely many configurations, so on this ring halting is always decidable — that is why there is a picture at all. The real busy beaver problem is not. Where the ring is wide enough to hold the whole computation the two agree exactly; where it is not, the tape wraps and the machine answers a different question. BB(5) needs 12,289 cells, so no ring you can draw will ever reach it.
