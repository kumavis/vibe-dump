## Building the Guide Tool

[0:09:05] Talking about modding systems, Cataclysm is a heavily data driven game. All of the nouns in the game, items, monsters, terrain, furniture, what limbs a character has and what kind of martial arts are defined in the data files written in JSON and many of the verbs the character can use are largely defined in JSON as well. I found myself answering questions about how the world of Cataclysm worked by searching through the game's data files. I would search for an item's name to find the ID and then search for that ID to find out what monsters dropped it or what locations I might find it in. This was really tedious and repetitive which was an immediate clue I should spend way more time than I would have spent looking up to create a tool to make it easier. I think I

[0:10:05] am over here somewhere maybe. I have definitely spent way more than six days on this thing. This is what The Hitchhiker's Guide to the Cataclysm looks like. It is an index of every item, monster, terrain, vehicle part, skill, tool quality, mutation, bionic, and a few other things in the game. The guide gathers up all of the game's data files and indices them and makes them linked and searchable. Each noun gets its own page with detailed information about the item like how big it is, what's it made out of, how much does it weigh. Each kind of thing has different kinds of information based on what's relevant for that thing. For a monster, you want to know what their offensive and defensive capabilities and their vision range is. For weapons you want to know how much damage they deal,

[0:11:07] how slow they are to swing and other information that's relevant to combat. For a vehicle part, you want to know how much power it produces or consumes and what skills you need to install or remove it. A lot of this kind of data is already visible in the game itself assuming you can find one of these things. But I think the really valuable thing that the guide does is that it shows the links between things like what skills do you need to repair an item? What books contain knowledge about those skills? What locations are those books found in? The goal of the guide is to make every relationship between the nouns in Cataclysm visible.
