## Basic Solver: Backtracking

[0:03:15] Basic algorithm to CSP is called backtracking algorithm. It is refined brute force approach. Variables are all assigned one after the other. The only Specialty is each time we assign a variable we will check the constraints, if the constraints are satisfied we move to the next variable using if the constraints are not satisfied, or if it fails, we move the next value into the domain and if there is foe no value left we backtrack. It is a simple algorithm. It is less than 10 lines of code but it works very well and if there is a solution to the problem it will find it. The only issue is that as we always try values in

[0:04:20] the same order the algorithm is domestic and we also return the same solution. Not ideal. But the fix is very simple. We just have to shuffle the domains before running the algorithm. If you are using external library make sure the selection process or values in the domains is random. We can also know the order we process the variables doesn't matter. It doesn't need to be random. And in fact, if you process first the variables with some smaller domains it can speed up significantly as they are more constrained and cause the minimum value heuristics.
